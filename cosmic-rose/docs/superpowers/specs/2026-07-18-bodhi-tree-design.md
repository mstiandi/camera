# 菩提古树 — 光之树重设计

## 目标
将现有硬边规则分叉的"光之树"替换为**月光檀香色调的菩提古树**——粒子极细如奶茶粉尘，沿遒劲不规则枝脉持续流动，末梢升腾消散如香火烟气。

## 视觉参考
- 粒子质感：极细粉尘，锐利硬边高斯核，无明显光晕
- 树形态：古籍菩提古树，枝干盘曲不对称，根系裸露
- 配色：根部暖奶油白 → 中段淡金微琥珀 → 末梢纯暖白渐变透明
- 氛围：月光下老树，圣洁静谧

---

## 设计

### 1. 树骨架（替代现有 treePos 生成）

**根部系 (Roots)**：主干底部 (y=0 附近) 向四周低角度伸出 4-6 条拱形曲线 (贝塞尔)。根部粒子沿曲线向外 → 向下 → 入地。

**主干 (Trunk)**：单条主贝塞尔曲线从 y=0 到 y=0.7，带微小弯曲 (control point 偏移 x≈0.04, z≈0.03)。略粗。

**主枝 (7-9条)**：从主干不同高度 (y=0.25~0.7) 自然伸出，每枝: 高度 + 水平角度 + 仰角 + 长度 各不相同，用二次贝塞尔 (起点 → 控制点 → 终点)。不对称分布。

**子枝 (每主枝 2-3条)**：从主枝中后段分叉，更细更短，末梢渐散。

**树冠消散区**：子枝末端粒子不返回闭合曲线，而是在终点区域轻微上升飘散。

### 2. 粒子流动系统（树态新增）

当前：粒子 spring 弹到 treePos 目标位置，静止。
改为：**每个粒子分配一条曲线段 (curve segment)**，沿曲线持续移动。

- `particleCurve[i]`: 该粒子所属曲线的索引 (0=root, 1-9=main branches, etc.)
- `particleT[i]`: 沿曲线的参数 t ∈ [0, 1]，每帧前进 Δt
- `particleSpeed[i]`: 该粒子的流动速度 (根部慢 0.04/s，枝干中速 0.12/s，末梢快 0.2/s)
- 到达 t=1 时：末梢粒子淡出消失，重置到所在曲线的 t=0 重新诞生
- 粒子位置 = 曲线在 t 处的插值 + 微小噪声偏移 (粉尘飘散感)

### 3. 粒子渲染

- **数量**：N = 18000（从 2500 提升）
- **大小**：0.018（从 0.08 缩小，约为 1/4.4）
- **纹理**：新 `mkDustSprite()` — 锐利粉尘点，径向渐变但极硬：
  - 0-0.02: white α=1.0
  - 0.02-0.08: α 急速衰减到 0.15
  - 0.08-1.0: α→0
  - 不加软光晕
- **Bloom**：树态下 threshold=0.6, strength=0.7, radius=0.4（柔和）

### 4. 配色

```
根部/主干: hsl(42°, 100%, 85%) → warm cream #FFF5E0
中段枝条: hsl(38°, 80%, 78%)  → pale gold #FFE4B5  
末梢粒子: hsl(35°, 60%, 92%) → near white, fade to transparent
```

粒子颜色随 t 在曲线上线性插值。

### 5. 交互（不变）

- 手掌张握 → 缩放树
- 手指左右 → 旋转树
- 无手 → 缓慢自动旋转
