# 粒子星球 — 手势交互

手掌控制粒子球壳：张开收缩，握拳扩张，食指旋转。

## 运行

```bash
cd D:\camera\particle-sphere
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

允许摄像头权限后，把手放到摄像头前即可。

## 交互

| 手势 | 效果 |
|------|------|
| 🖐️ 手掌张开 | 球壳收缩，粒子深入内部 |
| ✊ 握拳 | 球壳扩张，粒子向外扩散 |
| ☜ 食指左指 | 球壳左旋 |
| ☞ 食指右指 | 球壳右旋 |
| 无手 | 2 秒后自动缓慢旋转 |

## 技术

- Three.js 粒子系统 + UnrealBloomPass 霓虹发光
- MediaPipe HandLandmarker 手势识别
- 比率法手势检测（尺度不变）
